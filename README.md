One square picture that sums up Tuesday 17 November 2026, drawn for
[make.fun](https://make.fun/bounty/news-image-20261117)'s daily news-image bounty.

Four stories under the day's date: Kyiv struck as peace talks resumed; Washington
weighing a reported Iranian "dirty bomb" plot; winter rains wrecking tents in Gaza
as the UN appealed; and Trump in Manila before a Xi–Putin summit. A strip below
carries three more briefs of the day — Sudan's drone toll, Nvidia's chief
resigning, Alaska's Senate seat called for Peltola.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` copies `entry.png` (1024 × 1024, 121 KB) to the output directory after
checking its size and PNG header. The drawing itself lives in `art/nov17.html` —
plain HTML and SVG, rendered once at 1024 × 1024 — so the picture is reproducible
without a photo editor or an image library.
